# 片刻 UI 质感准则

这份准则是后续新增页面、功能区和交互的默认验收标准。它把“看起来高级、用起来顺手”拆成可以检查的实现规则。

## 1. 用色阶建立层次

- 页面、面板、输入区和浮层使用相邻的背景色阶，优先靠留白、间距和轻阴影分层。
- 不用纯黑边框或大面积高对比描边；只有需要表达状态时才提高边界对比度。
- 输入框聚焦使用“边界加深 + 双环柔和阴影”，避免突兀的亮色外框。
- 新组件应优先使用 `--line-soft`、`--line-quiet`、`--shadow-soft`、`--focus-border` 和 `--focus-halo`。

## 2. 让数字不抖动

- 统计数字、日期、距离、坐标和计时器使用 `font-variant-numeric: tabular-nums lining-nums`。
- 动态内容改变时，布局不应因为数字宽度变化而左右移动。
- 展开内容用自适应布局和高度动画，不在脚本里硬编码每一段的高度。

## 3. 内容出现要有“墨水落纸”的感觉

- 新增回忆、地点标签和时间节点可以使用 `.moments-ink-reveal`，让内容由轻微模糊自然变清晰。
- 这个效果只用于新增内容或状态切换，不对全站文字逐字播放，避免阅读被打断。
- 行内图标要和文字基线对齐；图标需要下移时以 `0.125em` 为起点微调。

## 4. 动效按交互性格分配

- 拖拽、滚动和地图镜头属于操作反馈，响应要快，松手后直接吸附到稳定状态。
- 收藏、保存、复制等成功反馈可以有一次轻微回弹；提示应自动消隐，默认不超过 2.5 秒。
- 面板展开、页面切换和列表更新使用可中断的短动画；新操作到来时取消旧动画，避免堆积和卡顿。
- 必须保留 `prefers-reduced-motion` 路径，用户关闭动态后不再播放过渡和回弹。

## 5. 暗色模式单独校准

- 暗色模式的白字会产生视觉光晕，正文默认降低一个字重档位，不改变标题层级关系。
- 暗色背景下仍使用层次色阶，不用纯黑背景配纯白文字；颜色和对比度要以长时间阅读舒适为准。

## 当前实现落点

- `src/quality-polish.css`：共享色阶、聚焦双环、数字稳定、内容显现和成功反馈。
- `src/motion.js`：`Motion.ink()` 与 `Motion.feedback()`，供新增板块复用。
- `src/footprints.js`：时间节点和移动段使用轻柔显现。
- `src/prototype.js`：自定义地点标签使用轻柔显现。
- `src/ui-template.html`：收藏操作使用轻微回弹反馈。

新增板块在交付前至少检查：空态、加载态、展开态、成功反馈、错误态、减少动态和窄窗口布局。
